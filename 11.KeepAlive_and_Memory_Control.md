## Setting Keep-Alive Globally

```bash
# Stop the server first
systemctl stop ollama

# Keep models loaded for 30 minutes after last use
OLLAMA_KEEP_ALIVE=30m ollama serve

# Keep models loaded indefinitely until explicitly stopped
OLLAMA_KEEP_ALIVE=-1 ollama serve

# Unload immediately after every request (no caching)
OLLAMA_KEEP_ALIVE=0 ollama serve
```

```bash
systemctl edit ollama
```

```ini
[Service]
Environment="OLLAMA_KEEP_ALIVE=30m"
```

```bash
systemctl daemon-reload

systemctl restart ollama
```

```bash
systemctl show ollama --property=Environment
```

```bash
# Run the model first
echo "Hi there!" | ollama run granite3.3:2b

# Run the ps command
ollama ps
```

## Setting Keep-Alive per Request

```bash
curl http://localhost:11434/api/chat -d '{
  "model": "granite3.3:2b",
  "messages": [{"role": "user", "content": "hi"}],
  "keep_alive": "5m",
  "stream": false
}'
```

```bash
ollama ps
```

## Forcing an Unload Right Now

```bash
curl http://localhost:11434/api/generate -d '{
  "model": "granite3.3:2b",
  "keep_alive": 0
}'
```

```bash
ollama stop granite3.3:2b
```

```bash
ollama ps
```

## Multiple Models in Memory at Once

```bash
# Allow up to 5 models loaded at once
# edit the unit file with `systemctl edit ollama`

[Service]
Environment="OLLAMA_MAX_LOADED_MODELS=5"

# or run the serve command with the environment variable 
# OLLAMA_MAX_LOADED_MODELS=5 ollama serve
```
