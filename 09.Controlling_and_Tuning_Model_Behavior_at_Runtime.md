# Controlling and Tuning Model Behavior at Runtime

## The /set Command

```text
/set parameter <k> <v>   # runtime params (temperature, num_ctx, etc.)
/set system <string>     # system prompt
/set history             # enable history
/set nohistory           # disable history
/set wordwrap            # enable wordwrap
/set nowordwrap          # disable wordwrap
/set format json         # force JSON output
/set noformat            # clear format
/set verbose             # show timings/token counts
/set quiet               # hide them
/set think               # enable thinking (reasoning models)
/set nothink             # disable thinking
```

```text
# Set command
/set system You are a terse Linux sysadmin. Answer in commands only.

# Question
Copy all files including hidden ones from folder A to folder B

# Answer
`cp -r /path/to/folder/A/* /path/to/folder/B/`

# Erase the system prompt
/set system ""
```

```text
# Set command
/set parameter temperature 1.5

# Question
Write a poem

# Answer
In Unix kernel deep,
Secrets safely it keeps.
Commands echo with silent might,
Guiding Linux through the night.

# Reset the temperature
/set parameter temperature 1.0
```

```text
# Set commands
/set format json
/set system Reply with a single JSON object. No prose and no markdown.

# Question
Convert this text to a 5W1H JSON: The Linux kernel was created by Linus Torvalds in 2005 after he graduated from the University of Helsinki with a BSc in Computer Science.

# Answer
{
  "Question": {
    "Who": "Linus Torvalds",
    "What": "created",
    "When": "2005",
    "Where": "University of Helsinki, Computer Science degree",
    "Why": "To develop an operating system kernel"
  },
  "Subject": "Linux Kernel"
}

# Reset
/set noformat
/set system ""
```

```text
# Default num_ctx is small (often 4096). Bump it before pasting a long doc.
/set parameter num_ctx 16384

# Output
Set parameter 'num_ctx' to '16384'

# Verify it took
/show parameters

# Output
User defined parameters:
num_ctx 16384


# Note: larger context costs RAM/VRAM. If the model fails to load
# or falls back to CPU, lower this value.

# Reset
/set parameter num_ctx 4096
```

```text
# Cap response length
/set parameter num_predict 300

```

```text

# the reasoning trace and want faster, shorter answers.

# Re-enable when you want the reasoning back
```

## Using the API to Control the Model

```bash
curl -s http://localhost:11434/api/chat -d '{
  "model": "'"$MODEL"'",
  "stream": false,
  "format": "json",
  "messages": [
    {
      "role": "system", 
      "content": "Reply with a single JSON object. No prose and no markdown."
    },
    {
      "role": "user", 
      "content": "Convert this text to a 5W1H JSON: The Linux kernel was created by Linus Torvalds in 2005 after he graduated from the University of Helsinki with a BSc in Computer Science."
    }
  ],
  "options": {
    "temperature": 0.2,
    "num_ctx": 8192,
    "num_predict": 300
  }
}' | jq -r '.message.content' | jq .
```

```json
{
  "Who": "Linus Torvalds",
  "What": "created the Linux kernel",
  "When": "2005",
  "Where": "University of Helsinki",
  "Why": "After graduating with a BSc in Computer Science"
}
```
