# Concurrency: Parallel Requests and the Queue

## How Many Requests One Model Handles at Once

```bash
# Update the unit file
cat > /etc/systemd/system/ollama.service.d/override.conf <<'EOF'
[Service]
Environment="OLLAMA_NUM_PARALLEL=4"
EOF

# Reload and restart
systemctl daemon-reload
systemctl restart ollama
```

```bash
MODEL=granite3.3:2b

# Run the model with an empty prompt to load it
ollama run $MODEL ""

# Check the size and note the increase
ollama ps
```

```bash
cat > $HOME/test.sh << 'EOF'
#!/bin/bash
MODEL=${MODEL}
N=${N:-4}

for i in $(seq 1 $N); do
  (
    T=$(date +%s)
    curl -s http://localhost:11434/api/generate \
      -d "{\"model\":\"$MODEL\",\"prompt\":\"Count to 50.\",\"stream\":false}" \
      -o /dev/null
    echo "Request $i: $(($(date +%s) - T))s"
  ) &
done
wait
EOF
```

```bash
# Make the script executable
chmod +x $HOME/test.sh

# Run it with 4 parallel requests
N=4 $HOME/test.sh
```

## How They Interact

```ini
[Service]
# keep models warm
Environment="OLLAMA_KEEP_ALIVE=-1"

# handle 40 requests per model concurrently
Environment="OLLAMA_NUM_PARALLEL=40"

# buffer up to 512 waiting requests
Environment="OLLAMA_MAX_QUEUE=512"
```
