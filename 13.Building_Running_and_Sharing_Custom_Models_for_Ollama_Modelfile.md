# Building, Running, and Sharing Custom Models for Ollama (Modelfile)

```text
# ollama run granite4.1:3b

# Tell the model its job
>>> /set system "You are commitwriter, a model that writes git commit messages. I give you a code change, and you reply with one commit message."

# Make the output steady
>>> /set parameter temperature 0.2

# Give it room to read a long diff
>>> /set parameter num_ctx 8192

# Paste the code change
>>> """
-    def get(self, key):
-        return self._store[key]
+    def get(self, key, default=None):
+        return self._store.get(key, default)
"""

# The model replies
Fix: add default value to get so a missing key no longer raises KeyError
```

```bash
ollama pull granite4.1:3b
```

## Step 2: Give It One Job with SYSTEM

```dockerfile
cat <<EOF > $HOME/commitwriter/Modelfile
# commitwriter - turns a code change into a commit message
FROM granite4.1:3b

SYSTEM """
You write git commit messages in Conventional Commits format.
Read the user's description or code diff. Reply with one commit message and nothing else.

Use this shape:
type(scope): short summary

An optional body that explains what changed and why.

Rules:
- type is one of: feat, fix, docs, refactor, test, chore.
- scope is optional and lowercase.
- the summary is under 60 characters, in the imperative mood, with no period at the end.
- do not add notes, options, or code fences.
"""
EOF
```

```bash
ollama create commitwriter -f Modelfile
```

```bash
ollama run commitwriter \
    "added a retry with backoff to the API client and a test for it"
```

```text
feat(api): add retry with backoff functionality

Implement exponential backoff for transient errors in the API client. Added corresponding integration test to verify the new behavior.
```

## Step 5: Teach the Format by Example with MESSAGE

```dockerfile
MESSAGE user added a retry with backoff to the HTTP client and a test for it

MESSAGE assistant feat(http): add retry with backoff to client

MESSAGE user fixed a typo in the README install section

MESSAGE assistant docs(readme): fix typo in install section

MESSAGE user renamed getUser to fetchUser across the codebase, no behavior change

MESSAGE assistant refactor: rename getUser to fetchUser
```

## Sharing Your Model

```bash
# Clone the repo
# git clone..

ollama create commitwriter -f Modelfile
```

```bash
# Register your machine by singing in
ollama signin

# Rename the model into your namespace (your username)
ollama cp commitwriter \
    $OLLAMA_USER/commitwriter

# Push it
ollama push $OLLAMA_USER/commitwriter
```

```bash
# Rename the model into your namespace
ollama cp commitwriter \
    $OLLAMA_USER/commitwriter:1.0

# Push it
ollama push $OLLAMA_USER/commitwriter:1.0
```
